# CSS Units, Box Model and Fonts

This is my CSS Units, Box Model And Fonts assignment.
In this task, I created a simple webpage using HTML and CSS.I created a div and added an image and a button inside it.
I used an external CSS file called style.css and linked it with the index.html file.
I used margin to give equal space from the left and right side of the screen.
I also added space from the top and bottom of the page using vh unit.
I used box-sizing to manage the size of the elements properly.
The image takes the full width of the div.
I styled the button and added a gradient background to it.
I also changed the button text color, font size and font family using CSS.
In this task, I did not use flex, absolute position or relative position as mentioned in the instructions.
This assignment helped me understand CSS units, box model, fonts, margins and basic button styling.
The main files used in this project are index.html and style.css.
