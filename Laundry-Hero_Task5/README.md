# Laundry Services Hero Section

This is my CSS assignment for creating a laundry service hero section.
In this task, I created a navigation bar with a logo, menu links and username.
I created the hero section using two divs.
The left side contains a heading, some text and a button.
The right side contains a laundry image.
I used inline-block to place the elements next to each other without using flex.
I also used viewport units like vw and vh to manage the size and spacing of the page.
I used CSS to change the text colors, button style, font size and image size.
The main files used in this project are index.html and style.css.
