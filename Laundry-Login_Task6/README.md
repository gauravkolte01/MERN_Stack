# Laundry Mart Login Page

This is my CSS login page assignment.
In this task, I created a login page for a laundry service.
The page has two sections. The left section contains a laundry image and the right section contains the login form.
I added email and password input fields with placeholder text.
I also added a Login button, Forgot Password link and Register Now link.
I used CSS Flexbox to arrange the two sections.
I also used 100vh for the height of the main container.
