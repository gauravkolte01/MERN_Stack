# Laundry Services Hamburger Menu

This is my CSS assignment for creating a hamburger menu for the laundry page.
In this task, I added a hamburger button to the mobile navbar.
The normal navigation links are hidden on mobile.
When the hamburger button is focused, the menu list is shown on the right side.
I used the CSS focus selector to show the menu without using JavaScript.
I also used position absolute for the menu list.
The page uses the laundry hero section from the previous task.
The main files in this project are index.html and style.css.
